Where the data comes from, where it is stored, how it is filtered

  • Comes from: USDA NASS Quick Stats, downloaded as a CSV (see the date in the comment at the top of this file).
  • Stored: The data is saved in mn_corn_production.csv in the same GitHub folder. The webpage loads this saved file instead of contacting USDA.
  • Filtered: The chart displays final annual production numbers, and the forecast table displays forecasts for the selected year.
