About the CSV you uploaded to class (Crop Progress, week ending Nov 1, 2026)

That export is a Crop Progress report, a weekly snapshot of field work. It isn't a production report. It has no county or multi-year rows. For Minnesota corn it has one useful number: 82% of the crop harvested, compared with an 85% five-year average. That means harvest is running a little behind normal. It says nothing about how big the crop is. If you load that file above, the page will tell you it has no production rows.

To get county-level production for the chart, open Quick Stats and choose Program: SURVEY → Sector: CROPS → Group: FIELD CROPS → Commodity: CORN → Data Item: CORN, GRAIN - PRODUCTION, MEASURED IN BU → Geographic Level: COUNTY → State: MINNESOTA → Years: 2021–2025. Then click "Get Data" and "Spreadsheet" and load the file here. County estimates for a crop come out the following February, so 2026 counties won't exist until 2027.
